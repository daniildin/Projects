# Petting Zoo Visit Planner

## Overview
This C# application helps plan school visits to a petting zoo by organizing students into groups and randomizing animal visits.

## Features
- Supports three schools with customizable group numbers.
- Randomizes animal visits for uniqueness.
- Displays assigned groups and animals.

## Usage
Run the program to generate group assignments for:
- **School A**: 6 groups (default)
- **School B**: 3 groups
- **School C**: 2 groups

## Code Overview
- `PlanSchoolVisit()`: Organizes the visit.
- `RandomizeAnimals()`: Shuffles animals.
- `AssignGroup()`: Divides animals among groups.
- `PrintGroup()`: Displays assignments.

## Example Output
```
School A
Group 1: rabbits ducks goats 
...
School C
Group 2: capybaras pigs alpacas 
```
