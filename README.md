# Challenge-project-branching-looping-CSharp
Starter and Solution code for the Challenge project: "Develop conditional branching and looping structures in C#" from the Microsoft Learn collection "Getting started with C#"


Contoso Pets - Case 3 & 4

Case 3: Ensure Age and Physical Description

Prompts the user to enter missing age and physical descriptions.

Skips entries with a default pet ID.

Ensures valid numeric input for age and non-empty descriptions.

Case 4: Ensure Nickname and Personality

Prompts for missing nicknames and personality descriptions.

Skips entries with a default pet ID.

Ensures non-empty inputs before updating records.

Both cases ensure all pet data is complete before proceeding.
