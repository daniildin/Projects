# Contoso PetFriends App - Search Enhancement  

## Overview  
This project involved updating an existing pet adoption application to enhance search functionality and improve user feedback during searches. The key improvements included supporting multiple search terms and refining the search status animation.  

## Features Implemented  
- **Multi-term Search:** Users can now enter multiple search terms for dog characteristics.  
- **Data Processing:** Inputs are stored in a sorted array, making searches more efficient.  
- **Improved Search Animation:** A countdown-based search status animation provides better user feedback.  
- **Formatted Data Output:** The application organizes and displays pet details in a clear format.
